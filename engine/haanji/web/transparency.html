Transparency लॉग

Har shaam har pack ke us din ki receipts ka ek Merkle root banta hai aur tenant ki Ed25519 key se sign hota hai. Woh root yahan dikhta hai aur roz GitHub ke transparency branch pe bhi commit hota hai — jise hum khud baad mein nahi badal sakte. Certificate Transparency jaisa, par bookings ke liye: agar kal koi receipt badli ya hataayi gayi, to aaj ka root use pakad lega.

Khud check karo

Export lo (api/receipts/export?pack=…), us din ki receipts ke chain_hash le kar pairwise sha256 karo (akela bacha hua apne aap se pair hota hai), root milna chahiye; phir signature root || day pe public key se verify karo:

import hashlib, json, urllib.request
from cryptography.hazmat.primitives.asymmetric.ed25519 import Ed25519PublicKey
base, pack, day = "https://haanji-engine.onrender.com", "dental_clinic", "2026-10-15"
exp = json.load(urllib.request.urlopen(f"{base}/api/receipts/export?pack={pack}"))
anc = json.load(urllib.request.urlopen(f"{base}/api/anchors?pack={pack}"))
layer = [bytes.fromhex(r["chain_hash"]) for r in exp["receipts"] if r["occurred_at"].startswith(day)]
while len(layer) > 1:
    layer = [hashlib.sha256(layer[i] + (layer[i+1] if i+1 < len(layer) else layer[i])).digest() for i in range(0, len(layer), 2)]
a = next(x for x in anc["anchors"] if x["day"] == day)
assert layer[0].hex() == a["merkle_root"]
Ed25519PublicKey.from_public_bytes(bytes.fromhex(anc["public_key"])).verify(bytes.fromhex(a["signature"]), layer[0] + day.encode())
print("anchor valid")
