Design system

Signboard साइनबोर्ड

Every Indian shop has a hand-painted sign: marigold on cobalt, thick bilingual lettering, a red stamp. All of HaanJi's UI (demo pages, owner console, receipts) speaks this one language. This page shows the tokens and components of static/signboard.css as they are; what you see here is the code.

Colour

Two primaries (cobalt, marigold), a paper (chalk), an ink, and two signal colours: sindoor for wrong or danger, leaf for right or verified. The console uses the same colours the other way round, on light paper. Every pair passes WCAG 2 AA contrast (a Playwright + axe test checks it).

Type

Bricolage Grotesque for display headings (bold, condensed, like a signboard); Yatra One for Devanagari (brush); Instrument Sans for body text; JetBrains Mono for numbers and codes: receipt codes, latency and phone numbers are always mono.

Frames (.frame) are a three-line painted border, marigold inside cobalt, that makes every card look like a sign. The receipt stamp (.stamp) is always tilted 3°, in sindoor ink, with mono text: the one look of a "seal", from the demo to the console.

Icons

All SVG, on a 24px grid with a 2px stroke, from Signboard.icon(name). Never an emoji in the UI: the test test_no_emoji_is_used_as_an_icon checks every page.

Motion

Three durations: micro 160 ms (hover, press), base 240 ms (reveal, panel), paint 400 ms (a repair's "paint over", a stamp landing). All of them respect prefers-reduced-motion: the animation then jumps to its end state. Motion only marks things that really happened: a fix, a seal, a tool that was ready early.

Rules

Bilingual, without making a joke of it

Devanagari only where a word carries weight: the wordmark, a section name, a stamp. Body text in the language people speak.

Numbers in mono

Every code, latency, number and time is mono. The eye sees at once that this is "data", not "talk".

Relative URLs

Every link is relative, so a page works behind any prefix (a Vercel rewrite, nginx). A test catches it.

Dark on demo, paper on console

The demo on cobalt (a sign), the console on chalk paper (a register). The same tokens, in reverse roles.

44px touch targets

Every button and input is at least 44px, for a thumb on a phone. Never a sideways scroll at 390px.

Honest states

Loading, empty, offline: every page has all three, and sample data shown offline is clearly labelled.

Using it

<link rel="stylesheet" href="static/signboard.css">
<script src="static/signboard.js"></script>
<i data-icon="phone"></i>            <!-- Signboard.mountIcons() inhe SVG bana deta hai -->
<span class="stamp">RECEIPT 2504-7863</span>   Signboard.stamp(el)   // mohar girti hai
Signboard.repairNode("rut kanal", "root canal")   // paint-over repair

The console (React) keeps the same tokens in console/src/signboard.css, and the components in Common.tsx: Chip, Stamp, Repair, Register, Tile, Waterfall.
