Design system

Signboard साइनबोर्ड

Har Indian dukaan ka ek hand-painted sign hota hai: cobalt pe marigold, moti bilingual lettering, ek laal mohar. HaanJi ki poori UI — demo pages, owner console, receipts — isi ek bhasha mein hai. Yeh page static/signboard.css ke tokens aur components ko jaise-ke-waise dikhata hai; jo yahan dikhta hai wahi code hai.

Rang

Do primary (cobalt, marigold), ek paper (chalk), ek ink, aur do signal rang — sindoor galat/khatre ke liye, leaf sahi/verified ke liye. Console pe wahi rang light paper pe ulte chalte hain. Har pair WCAG 2 AA contrast paas karta hai (Playwright + axe pass test mein hai).

Type

Display heading ke liye Bricolage Grotesque (bold, condensed, signboard jaisa); Devanagari ke liye Yatra One (brush); body Instrument Sans; numbers aur codes JetBrains Mono — receipt codes, latency, phone numbers hamesha mono mein.

Frames (.frame) teen-line painted border hain — cobalt ke andar marigold — har card ko sign jaisa banate hain. Receipt ki mohar (.stamp) hamesha 3° tilt pe, sindoor ink, mono text: yeh "seal" ka ek hi roop hai, demo se console tak.

Icons

Sab SVG, 24px grid, 2px stroke, Signboard.icon(name) se. UI mein emoji kabhi nahi — test test_no_emoji_is_used_as_an_icon har page ko check karta hai.

Motion

Teen durations: micro 160 ms (hover, press), base 240 ms (reveal, panel), paint 400 ms (repair ka "paint over", stamp ka girna). Sab prefers-reduced-motion ka sammaan karte hain — tab animation turant apni aakhri state pe. Motion sirf un cheezon pe jo sach mein hui hain: ek sudhaar, ek seal, ek tool jo pehle se taiyaar tha.

Niyam

Bilingual, bina mazaak ke

Devanagari sirf wahan jahan shabd ka weight ho — wordmark, section ka naam, mohar. Body text Hinglish, jaise log bolte hain.

Numbers mono

Har code, latency, number, time — mono. Aankh turant pakad leti hai ki yeh "data" hai, "baat" nahi.

Relative URLs

Har link relative hai, taaki page kisi bhi prefix ke peeche chale (Vercel rewrite, nginx). Test isko pakadta hai.

Dark on demo, paper on console

Demo cobalt pe (sign), console chalk paper pe (register). Tokens same, roles ulte.

44px touch targets

Har button aur input kam se kam 44px — phone pe angoothe ke liye. 390px pe horizontal scroll kabhi nahi.

Honest states

Loading, empty, offline — har page ke paas teeno hain, aur offline pe sample data saaf label ke saath.
