Kya ye asli phone call uthata hai?

WhatsApp par haan: Meta ke WhatsApp Cloud API number se seedha judta hai. Phone line ka code bhi taiyaar hai (Twilio number, Deepgram aur ElevenLabs ki awaaz), lekin uska kharcha alag hai aur keys aapki lagti hain. Browser demo mic se chalta hai.

Kaunsi bhashayein bolta hai?

Hinglish ke saath Tanglish, Benglish, Marathinglish, Punglish, Tenglish aur Gujlish: abhi 10 packs aur 7 bhashayein. Jawab Roman script mein aate hain, jaise log WhatsApp par likhte hain.

Agent ko samajh na aaye, ya caller insaan se baat karna chahe?

Jo pack mein nahi hai woh nahi bolta, daam bhi nahi. Caller insaan maange ya kaam call par na ho, to woh number le leta hai aur call console ki "Inhe wapas call karo" list mein aa jaati hai. Chalti WhatsApp chat aap "Khud jawab do" se khud bhi le sakte ho.

Galat booking ho gayi to?

Booking tabhi banti hai jab caller slot sunke haan bolta hai, aur agent ka sawaal aur caller ka jawab dono receipt mein sign hote hain. Console ke calendar se booking cancel ho sakti hai, aur customer ko WhatsApp par khabar chali jaati hai.

Mera aur customers ka data kahan rehta hai?

Aapke apne server par; code GitHub par khula hai. Calls 180 din baad mit jaati hain, aur customer ke kehne par uska record turant mit sakta hai.

Owner ko kya chahiye?

Bas phone ya laptop ka browser. Console mein aaj ki calls, calendar, customers aur settings hain; har nayi booking aapke Google, Apple ya Outlook calendar mein bhi aa sakti hai.
