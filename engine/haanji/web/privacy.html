Privacy aur data

Ye page batata hai ki HaanJi ka software kya rakhta hai, kitne din, aur customer apna data kaise dekh ya mita sakta hai. Jo dukaan HaanJi chalati hai, uski apni privacy policy bhi ho sakti hai.

Kya rakha jaata hai

  • Calls aur WhatsApp messages: caller ne kya kaha, agent ne kya jawab diya, aur caller ka number.
  • Bookings: service, din, time, kiske saath, aur customer ka naam aur number.
  • Receipts: har booking ka signed record. Isme naam aur number har customer ki alag chaabi se encrypted rehte hain.

Browser demo par awaaz ko browser ka speech recognition text banata hai (Chrome mein ye Google ki service hai). HaanJi ke server tak sirf text pahunchta hai.

Kitne din

Calls, WhatsApp messages aur missed calls 180 din baad apne aap mit jaate hain. Bookings aur receipts dukaan ka record hain, isliye woh rehte hain.

Call ki shuruaat mein bataana

Har call ek line se shuru ho sakti hai ki baat record ho rahi hai. Line dukaan khud likhti hai.

Customer ke haq

  • Dekhna: customer ke kehne par dukaan uske number par rakha sab kuch dekh sakti hai: bookings, calls aur receipts.
  • Mitana: customer ke kehne par uska record mita diya jaata hai. Receipts ki chaabi nasht hoti hai, isliye unme naam aur number phir kabhi padhe nahi ja sakte; receipt ki chain phir bhi verify hoti rehti hai.
  • Apni booking check karna: confirmation code se customer apni receipt browser mein khud verify kar sakta hai.

Public demo par

Is demo par login band hai, isliye koi bhi console dekh sakta hai. Wahan numbers ke sirf aakhri chaar ank dikhte hain, aur calendar ka secret link aur kisi number ka poora record band rehta hai. Demo par asli number dalne se pehle ye yaad rakhein.

Data kahan rehta hai

Jo server HaanJi chalata hai, usi par. Code GitHub par khula hai, to koi bhi dekh sakta hai ki upar likhi har baat code mein kahan hoti hai.

Upar ke din aur consent line is server ki asli settings se aate hain (/api/privacy/policy), isliye ye page har deployment par wahi batata hai jo wahan set hai.
